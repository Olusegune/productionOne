# Production One 0.14.5

## 100-style visual system

The style system now separates visual style from animation approach and world treatment. Users can combine a curated 100-style library with movement language such as restrained acting, stop-motion cadence, physics-driven animation, mechanical animation, or music-driven animation, plus world treatments such as contemporary West Africa, historical Lagos, Afro-futurist, biblical historical, fantasy, cyberpunk, or space opera.

The resulting style bible is carried into asset, storyboard, motion, and delivery prompts for world coherence.
