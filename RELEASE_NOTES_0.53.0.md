# Production One 0.53.0

- **A full in-app guide** (Help, Documentation, or F1): 14 chapters, a walkthrough of every screen, 14 screenshots from the app, search.
- **A sleeker default look:** cool graphite, one blue accent, one clean font (Geist). The warm Cinematic look is still a choice under Appearance.
- **A new splash screen** with an x to skip it (or Esc), a Help button, and the real version.
- **Desktop shortcut:** the installer adds one, and Help, Add Production One to the Desktop makes one for the portable program, so you can pin it.
- **Your pictures match your script:** a picture named after a character already in the project (marcus.png for MARCUS) is attached to that character instead of making a duplicate.
- The Assistant's plan panel no longer runs off the edge of the window.
- Includes 0.52.0's shape, camera, review and looks tools.

Not checked: the splash buttons and the desktop shortcut were not clicked in the packaged app; installers were not run on a clean machine. Mac builds are unsigned.
