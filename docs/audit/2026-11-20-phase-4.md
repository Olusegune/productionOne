# Phase 4 audit: camera and lighting (2026-11-20)

## Current state
- `direct.ts`: shot size, angle, lens (a default per shot size, editable), movement, composition, screen direction. 2D styles already skip lens words in the shot prompt.
- Lighting: one free-text string per shot (`lightingFor` from the scene time of day). No structure, no grade.
- UI: `DirectRoom.tsx` Camera, Composition, Blocking, Lighting folds.
- No field of view, sensor, focus, depth-of-field or preset concept; no suggestions.

## Decisions
- New optional `shot.camera` and `shot.lightingRecord`; existing fields untouched, so old shots and prompts are unchanged (tested).
- Lens stays in `shot.lens`; sensor is a separate assumption with "Super 35 assumed" when unset.
- Perspective is modelled as a function of distance only; the UI says a lens change alone only crops.
- Lighting record holds no grade fields (tested by key list). Grade is Phase 5.
- Suggestions are pure, never edit the plan, and cap confidence at "medium".
- Golden Path: optional "Camera and light" extra after the first shot uses it.
