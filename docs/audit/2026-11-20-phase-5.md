# Phase 5 audit: non-destructive grading (2026-11-20)

## Current state
- No grading anywhere. Lighting was a text line (Phase 4 added a structured lighting record). The only colour tooling was the backdrop colour reader and the app's own appearance "looks" (themes), which are unrelated.
- Pictures are files in the project assets folder, referenced by queue jobs; nothing writes over them.

## Decisions
- A grade is a pure metadata record; the transform is a pure function of original pixels, so re-grading cannot compound and the original cannot change.
- Grade fields are kept apart from lighting; `contrast` is the one shared name and the docs and a test say how they differ.
- LUT import is deferred; the grade has no LUT field and the export says `lut: null`.
- Technical QA input is always the original (`qaInput`).
- Preview only, on storyboard frames; pixels are not exported.
