# Phase 2 audit: layers, propagation, fit (2026-11-20)

## Current state
- Style: `StyleBible` per project with an optional `asset.style` override (kept separate from identity already). Identity facts in `identityFacts()`; a fixed sentence says "keep the same body proportions".
- Prompts: `buildViewPrompt` (sheets), `buildShotPrompt` (storyboard frames), `autopilot.ts` (Assistant). All three now take the proportion wording as an optional input.
- Queue: `ImageJob` had style name and fingerprint but no record of references or proportions used.
- Review: per-job `approve` / `reject` already; no cross-view approval.
- Imported pictures live in `assetRefs`; there was no redesign workflow. No fit or scale logic.

## Decisions
- Layers are separate records; helpers in `characterLayers.ts` make the independence testable.
- Wording is added only where a profile differs from Natural, so no profile means identical prompts (golden test, Phase 1 fixture).
- `provenance` on each job stores a copy of the profile and the references; stale approved output is reported, never regenerated or re-approved.
- Fit rules are proposals in three kinds; only approved "fit" rules reach prompts; intentional cramped/oversized stays possible; decided rules are never overwritten.
- Redesign never touches the original; landmarks are estimates; warp is labelled preview only; the redesign is a generated candidate approved on request.
- Scale and Fit: one convention (metres), sizes "illustrative" unless supplied as verified.
