# Presets index (0.52)

Presets are starting points. Applying one copies values into your record; every value stays editable and nothing else changes. The tables below are generated from the code and a test keeps them equal.

- **Proportion starter profiles** (Natural, Elongated, Compact, Large-headed, Long-limbed, Angular, Rounded, Custom): numbers and notes in `proportions.md`.
- **Camera presets** (eight) and **lighting presets** (eight), with sensor sizes and camera heights: `camera-lighting.md`.
- **Fit rule formulas** and the Scale and Fit sheet: `character-layers-and-fit.md`.
- **Looks** are yours: the app ships none. `grading-and-looks.md` explains the transform.

No preset names or emulates real camera, lens or lighting equipment.
