# Production One 0.56.0

- **First run:** a one-minute tour (Help > Quick Tour), and "Make my first picture" on Projects: one picture, with the model and estimated cost shown before you press the button.
- **Prices:** every Generate button shows an estimate (a typical price, or yours from the spending limit). The real charge is on your provider account.
- **Remove from project:** characters, costumes, props and sets can be removed from Design. It asks first, clears the item from shots, notes, proportions, fit rules, the blocking map and review findings, keeps the picture files on your computer, and offers Undo. Items named in the script come back if you analyze the script again.
- Fixed a false "no key" dialog after making a first picture; the lighting test now explains when a shot has no character.

Not checked: Remove from project was tested by unit and component tests, not in the packaged app; the lighting test on a shot with a character was not run live; installers were not run on a clean machine. Mac builds are unsigned.
