# Production One 0.46.1

**Costumes and props, found and used.**

## New
- **Costumes from the script.** What each character wears, as the script describes them, becomes a costume with the script's own words, so the wardrobe sheet starts from them. Previously Costumes stayed empty unless you added one.
- **Costumes and props in the storyboard frames.** Master and dialogue shots carry the costume and the nearby props; the prompt states them; approved costume and prop pictures go along as references; a prop that returns in several scenes gets an insert shot.

## Fixed
- Prop noise: a bell ringing, a lift passing and a simile are no longer props; photograph and picture are one prop.
