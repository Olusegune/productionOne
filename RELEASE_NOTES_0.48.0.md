# Production One 0.48.0

**Edit images without touching the original, enlarge them, and bring in many images at once.**

## New
- **Image quality** now has **Brightness** and **Contrast**, and **Colour strength** all the way down is black and white. Every save makes a new file and a new revision; the original is kept.
- **Enlarge 2x or 4x** with a smooth filter. It makes the picture bigger and adds no detail: it is not an AI upscaler.
- **Image quality in the Director's room**, for a scene's storyboard frames.
- **Add several images at once** (up to 24) in Add to the bible: one item per image, named from its file name, each image the approved reference. Good for a folder of Midjourney images.

## Not included
- An AI upscaler (Magnific, Topaz, Real-ESRGAN) or another image model. They need your key or a local install and a cost decision.
- A Midjourney connection: it has no public one.

## Not checked
- A 4x enlargement on real frames, and the light theme.
