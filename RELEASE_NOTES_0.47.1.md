# Production One 0.47.1

**Quieter type, an icon for each kind of content, the art style applied in full, and regenerated frames you can see.**

## Fixed
- **Art style.** Storyboard frames now carry the whole art style near the top of the prompt, and no longer ask for a "photographic" frame, so painted, illustrated and animated styles stay that way. Copy-prompt and export-all-prompts carry the whole style too.
- **A regenerated frame** now shows on its card with Approve and Reject. Before, the card kept showing the old approved picture.

## Changed
- Sleeker, quieter titles in every look.
- An icon for characters, costumes, props and sets, and for each reference sheet (Identity, Turnaround, Expressions and the rest).
