# Production One 0.54.0

- **A storyboard from your own pictures, without a script.** Add your pictures as characters, places and props, then type your story one line per beat (for example "Marcus finds the lantern on the Old Harbour pier at dusk"). The Assistant turns your own words into scenes using your items, with no language model and nothing sent anywhere, then plans the shots.
- With a writing model, a one-line idea is now written using the characters, places and props you already have.
- After you add pictures to a project with no story, the Assistant asks you for one.
- **Fixed:** reading a script used to remove items made from your own pictures if the script did not name them. They are now kept.

Not checked: the outline reader was not tried on real user outlines or in the packaged app; installers were not run on a clean machine. Mac builds are unsigned.
