# Production One 0.50.0

**2D art styles, starter assets from an idea, and places that stay the same place.**

## New
- 38 two-dimensional style presets in six families (drawn and cel, anime-inspired, storybook and painterly, graphic and vector, comics and ink, pixel art), searchable under a **2D** chip. Five existing presets were reused and keep their names.
- Each style's settings are compiled into the request, with photographic and 3D defaults left out and intentional paper, brush and print texture kept.
- A different style for one asset, with picture-by-picture "made in an earlier style" marks. A style change never re-approves anything.
- **Reinterpret in <style>** makes a reviewable new revision of an approved picture; the original is kept.
- Add a character, prop or place from a description (and, for a place, its layout), then **Add and make a first concept**.
- A place's layout is repeated in every view and every storyboard shot set there.

## Be aware
- No 2D preset has been tried on a real image model. Request construction is tested; how well each model draws each style is **not**. Make one view first.
- The gallery preview is a schematic swatch, not a generated example.
- The app makes flat raster pictures: not vector files, layered files, rigs or animation.

## Not checked
- Visual quality of any 2D style on any model, the light theme, and pixel-art grid accuracy.
